# 画像の差し替え方法

現在このサイトは、実写真がまだ無い状態でも見た目が破綻しないよう、
すべての画像箇所を装飾プレースホルダー（グラデーション＋アイコン）で
表示する設計になっています。画像を用意でき次第、以下の手順で差し替えてください。

## 1. 画像を配置するフォルダ

| フォルダ | 用途 |
| --- | --- |
| `public/images/hero/` | ファーストビュー用（現在は背景グラデーションのみで運用、写真を使いたい場合はここに配置） |
| `public/images/services/` | サービス一覧カードの画像（任意） |
| `public/images/before-after/` | ビフォーアフター事例の写真 |
| `public/images/testimonials/` | お客様の声に顔写真やイニシャルアイコンを使う場合（任意） |

## 2. ビフォーアフター画像の差し替え

`src/data/beforeAfter.ts` を開き、該当する事例の `beforeImage` / `afterImage` に
画像パスを入力してください。

```ts
{
  id: "case-1",
  title: "エアコン内部のカビ・ホコリ",
  service: "エアコンクリーニング",
  beforeImage: "/images/before-after/aircon-01-before.jpg",
  afterImage: "/images/before-after/aircon-01-after.jpg",
  comment: "分解洗浄で内部のカビ・ホコリを徹底除去しました。",
}
```

空文字 `""` のままにしておくと、自動的に装飾プレースホルダーが表示されます。

## 3. 事例を追加する

`beforeAfterItems` 配列に新しいオブジェクトを追加するだけで、
ビフォーアフターセクションに自動で表示されます。

## 4. 推奨画像仕様

- 形式: JPG / PNG / WebP（WebP推奨・軽量で表示が速くなります）
- 比率: 正方形（1:1）を推奨（レイアウトが正方形グリッドのため）
- 容量: 1枚あたり300KB以下を目安に圧縮してください（表示速度維持のため）
- Next.js の `<Image>` コンポーネントで自動最適化・遅延読み込みされます

## 5. OGP画像（SNSシェア時のサムネイル）について

`src/app/opengraph-image.tsx` にてブランドカラーとロゴマークから
自動生成しています。実写真を使いたい場合は、このファイルを
`public/images/` 内の画像を参照する形に書き換えてください。
